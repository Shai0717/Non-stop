# Non-stop

Kolor 프레임워크 기반 Kotlin 플러그인입니다. 생존·모험 모드 플레이어가 한 틱이라도 제자리에서 멈추면 해당 월드의 스폰으로 돌아갑니다. 바닥 제작과 자동 배출 화로로 GUI를 열지 않고 아이템을 만듭니다.

Paper 플러그인 이름은 **Non-stop**이며 Gradle 그룹 및 Kotlin 패키지는 `io.github.Shai0717.stopreset`입니다.

## 설치 및 시작

- 빌드: Java 25와 Gradle로 프로젝트 폴더에서 `gradle build`. `StopReset` 및 `Kolor` 폴더가 같은 상위 디렉터리에 있어야 합니다. Gradle composite build가 `../Kolor`를 로컬 의존성으로 가져옵니다.
- `Kolor/build/libs/Kolor-1.0.0.jar`와 `StopReset/build/libs/Non-stop-1.1.0.jar`를 Paper 26.3 서버의 `plugins` 폴더에 넣고 재시작합니다. Kolor가 먼저 로드되도록 설정되어 있습니다. Kolor 로더가 최초 시작 시 Maven Central 미러에서 Kotlin 표준 라이브러리를 받으므로 첫 실행에는 저장소 접근이 필요합니다.
- OP 또는 `nonstop.admin` 권한이 필요합니다.

| 명령어 | 기능 |
|---|---|
| `/non-stop start` | 멈춤 감지 시작 |
| `/non-stop stop` | 멈춤 감지 중지 |
| `/non-stop status` | 감지 상태와 고급 도구 선택 확인 |
| `/non-stop tool pickaxe` | 고급 도구 레시피를 곡괭이로 선택 |
| `/non-stop tool axe` | 고급 도구 레시피를 도끼로 선택 |

기본 상태는 멈춤 감지 중지, 곡괭이 선택입니다. 서버 재시작 시 기본 상태로 돌아갑니다. 제작과 화로 기능은 멈춤 감지를 중지해도 계속 작동합니다. 명령 등록과 Kolor 모듈 생명주기 및 예약 작업은 Kolor API를 사용합니다.

`/non-stop`, 하위 동작, 도구 종류는 Brigadier 리터럴 명령으로 등록되어 탭 자동완성을 지원합니다.

현재 청크 순회와 아이템 그룹 제작은 Paper 메인 스레드의 전역 스케줄 작업을 사용합니다. 따라서 이 플러그인은 Paper 26.3을 대상으로 하며, Folia 지원은 보장하지 않습니다.

## 이동 규칙

매 서버 틱마다 생존·모험 모드의 살아 있는 플레이어의 수평 이동 거리 `sqrt(dx² + dz²)`와 시야 회전을 비교합니다. 직전 틱보다 **0.01블록 미만** 이동했고 시야각 변화도 **0.1도 미만**이면 월드 스폰으로 즉시 이동하고 소리와 액션바를 표시합니다. 수평 이동이 거의 없더라도 시야를 돌리면 해당 틱의 활동으로 간주합니다. 좌우 시야각의 -180도/180도 경계도 연속적으로 계산합니다. 달리기 시작, 스폰 복귀, 접속 또는 월드 변경 후에는 첫 가속을 위한 4틱 유예를 줍니다. 수직 위치 변화만으로는 멈춤을 피할 수 없습니다.

## 바닥 제작

아이템을 단단한 블록 위에 떨어뜨리면 5틱마다 최대 1.5블록 거리의 재료를 확인합니다. 결과에는 소리와 입자가 표시됩니다. 이름 변경 등 메타데이터가 있는 아이템은 소비하지 않습니다.

| 일반 블록 위 재료 | 결과 |
|---|---|
| 원목 또는 나무 1개 | 해당 나무 판자 4개 |
| 판자 2개 | 막대기 4개 |
| 판자 4개 | 작업대 1개 |
| 조약돌 8개 | 화로 1개 |
| 석탄 1개 + 막대기 1개 | 횃불 4개 |

여러 종류의 판자는 혼합할 수 있습니다. 표피를 벗긴 원목과 네더의 자루·균사도 해당 판자로 변환됩니다.

### 작업대 위

재료가 **같은 작업대 블록 바로 위**에 놓여 있어야 합니다.

| 재료 | 결과 |
|---|---|
| 판자·조약돌·철괴·다이아몬드 중 한 종류 3개 + 막대기 2개 | 나무·돌·철·다이아몬드 곡괭이 또는 도끼 1개 |
| 조약돌·철괴·다이아몬드 중 한 종류 2개 + 막대기 1개 | 돌·철·다이아몬드 검 1개 |
| 철괴 3개 | 양동이 1개 |
| 철괴 4 / 5 / 7 / 8개 | 철 부츠 / 투구 / 각반 / 흉갑 1개 |

곡괭이와 도끼는 재료 수가 같으므로 관리자가 위 명령어로 서버 전체에 적용할 결과를 선택합니다. 재료가 여러 레시피에 맞으면 도구·검을 우선하고, 그다음 철 갑옷(흉갑부터)과 양동이를 판정합니다. 일반 블록에서는 화로, 작업대, 횃불, 막대기, 원목 순으로 판정합니다.

레시피가 즉시 적용되므로 재료를 모을 때는 필요한 수량을 한 번에 떨어뜨리세요. 특히 철괴 3개는 양동이가 되고 판자 2개는 막대기가 됩니다. 막대기와 다른 재료를 따로 떨어뜨리면 먼저 놓은 재료가 다른 레시피로 소비될 수 있습니다. 제작 결과는 다시 제작되는 것을 약 2초간 방지합니다.

## 자동 배출 화로

일반 화로 바로 위에 떨어진 아이템만 흡수합니다. 용광로·훈연기는 해당하지 않습니다.

- 연료: 석탄, 숯, 실제로 화로 연료로 사용할 수 있는 판자와 원목.
- 재료: 철·금·구리 원석, 생고기(소·돼지·닭·양·토끼), 생대구·생연어, 다시마, 모래·붉은 모래, 조약돌.
- 기존 화로 인벤토리와 바닐라 제련 시간·연료를 사용합니다. 서로 다른 재료는 한 슬롯에 섞을 수 없고, 슬롯이 가득 찼으면 남은 아이템은 바닥에 그대로 둡니다.
- 이 방식으로 재료나 연료를 받은 화로는 제련 완료 결과를 위로 자동 배출합니다. 다른 플러그인이나 호퍼가 결과를 먼저 변경한 경우 배출하지 않고 서버 로그에 경고합니다.
- 제련할 재료와 연료가 있는 동안에는 해당 청크를 플러그인 티켓으로 유지하므로 플레이어가 떠나도 제련이 진행됩니다. 작업이 끝나거나 연료가 떨어지면 티켓을 해제합니다. 활성 화로 위치는 저장되어 서버 재시작 후 복구됩니다. 화로 수가 많으면 유지되는 청크도 많아질 수 있습니다.
